2. Model download

The classifier is about 137 MB and is downloaded once, then cached. It is not bundled with the extension so that a new model does not require a new release. Every file is checked against a checksum built into this extension before it is used.

What to expect

  • Likely-AI passages are dimmed, never hidden, with a dashed left edge.
  • Only runs of at least 150 words are marked. Detectors are near chance on short spans, so short ones are deliberately left alone.
  • English only. Other languages are skipped rather than guessed at.
  • It is tuned to avoid false flags on human writing, which costs recall. It will miss AI text — that is the intended direction of the trade.
